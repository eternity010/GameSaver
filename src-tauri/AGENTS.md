后端模块应保持命令层、业务流程层、存储层、共享类型层分离。Tauri command 只负责参数校验、状态锁获取、调用领域函数和返回结果，不应堆叠复杂业务逻辑。

新增或修改命令时，必须同步确认目标实现真实存在、已在 `src-tauri/src/lib.rs` 注册，并确认前端 `src/api.ts` 有对应封装或调用方不需要前端入口。

备份、恢复、迁移、学习存档属于高风险文件操作。修改这些路径时必须优先保证路径安全、事务性、错误可解释，并避免静默覆盖或删除用户数据。

共享结构应放在 `src-tauri/src/shared/`，只定义跨模块 DTO、配置和持久化结构，不应加入业务流程。

修改后端 Rust 代码后，至少运行 `cargo check --manifest-path .\src-tauri\Cargo.toml` 验证引用、注册和类型关系。
