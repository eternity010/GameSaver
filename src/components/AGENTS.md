Vue 组件只负责展示、基础格式化和事件 emit，不应直接调用 Tauri API，也不应持有复杂异步流程。

页面组件的业务状态、任务轮询、确认弹窗、toast 和数据刷新应下沉到 `src/composables/`。组件接收 props、展示状态、触发事件，避免复制后端或 composable 中的判断逻辑。

涉及产品文案时，优先使用用户可理解语言。规则 ID、hash、路径明细、诊断日志等技术细节应默认折叠，只在高级区域展示。

组件新增 props 或 emits 时，必须同步确认父组件传参与事件绑定真实存在，避免模板引用悬空。

修改 Vue 组件后，至少运行 `npm run build` 验证类型和模板绑定。
